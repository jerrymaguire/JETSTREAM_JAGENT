# 前端工作台设计

## 1. 设计定位

这是开发者高频使用的 Agent 工作台，不是营销页面。第一屏直接进入可用的对话界面。

设计参数：

- `DESIGN_VARIANCE: 3`
- `MOTION_INTENSITY: 2`
- `VISUAL_DENSITY: 8`

视觉原则：

- 安静、清晰、信息密度高。
- 以边框、背景层级和留白分区。
- 不堆叠装饰卡片。
- 状态颜色只表达语义。
- 单一蓝色交互强调色。
- 支持浅色和深色。

## 2. 主布局

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 顶栏：AgentShow | workspace | model | run status | settings                │
├───────────────────┬──────────────────────────────────────┬──────────────────┤
│ 左栏 280px        │ 中央工作区                            │ 右栏 360px       │
│                   │                                      │                  │
│ 新建会话           │ Chat | Trace | Artifacts             │ Inspector        │
│ 搜索               │                                      │                  │
│ 会话列表           │ 对话消息或轨迹画布                    │ 调用详情          │
│ 工作区切换         │                                      │ Context / Usage   │
│                   │                                      │ Approval          │
├───────────────────┴──────────────────────────────────────┴──────────────────┤
│ Composer：附件 | 模型 | Skill | 工具策略 | Plan/Execute | 发送/停止           │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 3. 顶栏

显示：

- 当前工作区。
- 当前模型。
- Run 状态。
- token 和成本入口。
- Provider/API Key 设置。
- 主题切换。

交互：

- 点击模型打开模型选择器。
- 运行中显示 Stop。
- 审批等待时显示醒目状态。

## 4. 左栏

### 会话

- 新建对话。
- 搜索。
- 按更新时间排序。
- 显示标题、最后消息摘要、模型、时间。
- 支持重命名、归档和删除。
- 同一对话可进行多次普通交流。
- 同一对话可以显示当前 Goal 和迭代状态。

### 工作区

- 当前工作区名称。
- 切换目录。
- 信任状态。
- 项目 Skill 数量。

### 分组

- Today
- Yesterday
- Previous 7 days
- Older

## 5. Chat 视图

消息类型：

- 用户消息。
- Agent 文本。
- 思考摘要。
- 工具调用块。
- 工具结果块。
- 审批块。
- 错误块。
- 上下文压缩提示。

工具调用块默认显示：

- 工具图标。
- 工具名。
- 一句摘要。
- 状态和耗时。

展开显示：

- 参数。
- 输出。
- 错误。
- 输入输出 token。

流式回答：

- 文本 delta 连续追加。
- 工具开始前保留当前位置。
- 工具结果后继续生成。
- 完成时用 `message_end` 权威消息替换临时文本。

### 5.1 Goal 模式

入口：

- 顶栏显示“设定目标”。
- Composer 提供“目标模式”。
- 已有对话可以从当前上下文创建 Goal。

Goal 编辑表单：

- 目标。
- 完成标准，可添加多条。
- 验收方式。
- 约束。
- 最大迭代数。
- 最大时长。
- Token 和成本预算。

Goal 卡片固定在消息流顶部：

- 状态。
- 当前迭代。
- 总进度。
- 完成标准列表。
- 已用时长、token 和成本。
- Pause、Resume、Cancel。

每条迭代显示：

- `Iteration N`
- 本轮计划。
- 关联 Run。
- 工具证据。
- 结果摘要。
- 继续、重规划、阻塞或完成判定。

状态：

- planning：正在规划下一轮。
- running：Agent 正在执行。
- verifying：正在验收。
- waiting_user：需要用户决策或审批。
- paused：用户暂停。
- completed：全部 required criteria 通过。
- blocked：无法继续。
- budget_exhausted：预算耗尽。

交互规则：

- Goal 运行中可以继续发送 steer。
- 新建普通消息不自动关闭 Goal。
- 创建新 Goal 前必须结束或取消当前 active Goal。
- 页面刷新后恢复 Goal 卡片和当前 Iteration。

### 总览

### 瀑布

- 名称。
- 摘要。
- 开始位置。
- 条形。
- 时长。

### 详情

### 筛选

- GoalIteration。

## 7. Composer

组成：

- 多行输入。
- 附件。
- 模型选择。
- 思考等级。
- Skill 选择。
- Plan/Execute 切换。
- 工具可见性摘要。
- 发送或停止。

快捷键：

| 快捷键 | 行为 |
|---|---|
| `Enter` | 发送 |
| `Shift+Enter` | 换行 |
| `Ctrl+L` | 聚焦输入 |
| `Ctrl+K` | 会话搜索 |
| `Esc` | 关闭浮层或停止确认 |
| `Ctrl+Enter` | 启动或继续 Goal |

## 8. Provider 与 API Key 设置

### Provider 列表

- Provider 名称。
- 协议。
- Base URL。
- 凭据状态。
- 最后测试时间。
- 启用状态。

### 添加 Provider

字段：

- 名称。
- 协议：OpenAI-compatible / Anthropic / custom。
- Base URL。
- API Key。
- 额外 Header，P1。

保存后：

- API Key 变成掩码。
- 显示“测试连接”。

### 模型

- 模型 alias。
- 上游模型 ID。
- context window。
- max output。
- 工具支持。
- 推理支持。
- 价格。

## 9. 工具与审批

### 工具页

- 工具列表。
- 风险。
- 权限。
- 是否审批。
- 启用状态。

### 审批弹窗

## 10. Skill 页

- 名称。
- 描述。
- 版本。
- owner 和 maintainers。
- 来源。
- 作用域。
- 路径。
- 是否受信任。
- 是否启用。

## 11. Memory 页

- 按项目分组。
- 类型筛选。
- 搜索。
- 查看正文。
- 来源和更新时间。
- 删除。
- 手动新增。

## 12. Eval 页

当前只评测单 Agent Strategy，不显示 Multi-Agent 或 Subagent。

页面：

- Task 列表。
- Strategy 列表。
- Experiment 列表。
- Trial 结果。

Experiment 摘要：

- execution_status。
- outcome_status。
- gate_status。
- pass、fail、unknown。
- 执行错误和取消。
- 耗时、Token 和成本。

Trial 详情：

- 真实 Trace。
- 实际模型请求。
- 工具记录。
- 最终 Artifact。
- Diff。
- Program Grader。
- LLM Judge。
- Human Review。

版本比较：

- 新旧 Strategy 逐题结果。
- 关键旧能力是否退化。
- 观测通过比例。
- pass@k 和 pass^k 只在条件满足时展示。

Skill 验证：

- 显式加载。
- 自动选择正例。
- 反例。
- 缺输入。
- 执行失败。
- 新版本效果对比。

## 13. 状态设计

### 空状态

- 无会话：新建会话或打开示例。
- 无 Provider：引导配置 API Key。
- 无 Trace：运行第一条消息后生成。

### 加载

- 消息骨架。
- Trace 骨架。
- Provider 测试进度。

### 错误

- 密钥失败：设置页内联。
- 模型失败：对话内错误块。
- Pi 崩溃：会话顶部错误条，可重启。
- 工具失败：对应工具块显示错误。

## 14. 可访问性

- 全键盘可操作。
- 状态不只靠颜色。
- 对比度达到 WCAG AA。
- 动画支持 reduced motion。
- 弹窗管理焦点。
- Trace 提供表格视图。

## 15. 响应式

- 1440px：三栏完整。
- 1024px：右栏变抽屉。
- 768px：左栏抽屉，中央单列。
- 手机：适合查看和发送消息，复杂 Trace 建议横屏或桌面。
