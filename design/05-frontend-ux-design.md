# 前端与交互设计

## 1. 设计阅读

该页面是面向开发者的轨迹分析工作台，不是营销页。视觉应安静、密集、结构清楚，优先服务扫描、比较和定位。

设计参数：

- `DESIGN_VARIANCE: 3`
- `MOTION_INTENSITY: 2`
- `VISUAL_DENSITY: 8`

参考图提供三项有效结构：

1. 左侧会话或工作区导航。
2. 中央按时间排列的轨迹总览与调用列表。
3. 右侧调用详情检查器。

AgentShow 保留该三栏结构，但增加明确的 KPI 摘要、轮次导航、可缩放时间轴、筛选状态和通用导入入口。

## 2. 页面布局

### 2.1 桌面端 1440 x 900

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ AgentShow  |  支付会话文档与 FAQ 整理  |  成功  [导入] [示例] [主题]          │
├───────────────┬──────────────────────────────────────────────┬───────────────┤
│ 会话           │ 总时长 3.40s  轮次 1  调用 2  错误 0         │ 调用详情       │
│ 搜索           ├──────────────────────────────────────────────┤ 名称           │
│ 最近会话       │ 时长 | 轮次 | 调用    [筛选] [搜索]  [缩放]  │ 状态 / 类型    │
│ 示例会话       ├──────────────────────────────────────────────┤ 开始时间       │
│                │ LLM   ████        █████████                   │ 总时长         │
│ 本地会话       │ Tool      ███████████                          │ Token          │
│                ├──────────────────────────────────────────────┤ 概览 | 预览 | 原始│
│                │ 时间刻度 0s        1s        2s        3.4s   │ 摘要           │
│                │ 1  写入支付会话文档       ███████              │ 输入预览       │
│                │ 2  整理 FAQ 与历史问题          ███████        │ 输出预览       │
│                │                                              │ 父子关系       │
└───────────────┴──────────────────────────────────────────────┴───────────────┘
```

尺寸建议：

- 顶栏：56px。
- 左栏：248px，可折叠到 56px。
- 右栏：340px，可折叠为抽屉。
- 中央区域：自适应，最小 480px。
- 行高：紧凑 36px，标准 44px。
- 时间刻度高：36px，吸顶。
- 总览轨道高：96px。

### 2.2 平板 768 至 1199

- 左栏变为抽屉。
- 右栏变为选中时从右侧滑出的面板。
- 顶栏仍保留会话标题和摘要。
- 筛选以弹出层显示。

### 2.3 手机小于 768

- 单列布局。
- 顶栏只保留返回、标题和更多菜单。
- KPI 使用两行可横向滚动的紧凑指标条。
- 总览轨道可折叠。
- 点击调用后底部抽屉显示详情。
- 时间轴支持水平滚动，不强制压缩文本。

## 3. 信息层级

### 3.1 顶栏

- 产品名 `AgentShow`。
- 当前会话标题。
- 状态标签。
- 导入按钮。
- 示例按钮。
- 主题切换。
- 更多菜单。

### 3.2 左栏

- 会话搜索。
- 最近打开。
- 示例会话。
- 本地导入会话。
- 每个列表项显示标题、Agent、时间、时长。
- 底部提供本地数据管理入口。

### 3.3 KPI 摘要

固定展示：

- 总运行时长。
- 轮次。
- 调用数。
- 错误数。

可选展示：

- 活跃时长。
- Token 总量。
- 模型。

KPI 不使用独立卡片，使用一条带分隔线的指标带，避免卡片套卡片。

### 3.4 工具栏

- 视图切换：`时长`、`轮次`、`调用`。
- 筛选按钮，显示当前筛选数量。
- 搜索输入。
- 缩放控制。
- 密度切换。

### 3.5 总览轨道

泳道：

- Agent。
- LLM。
- Tool。
- Conversation。
- Error 标记。

用途：

- 展示完整会话密度。
- 显示当前可见时间窗口。
- 点击空白处定位时间。
- 点击条形选择调用。
- hover 显示简要 tooltip。

### 3.6 瀑布列表

每个调用行包含：

- 序号或轮次标记。
- 类型图标。
- 名称。
- 内容摘要。
- 时间条。
- 持续时长。
- 状态。
- 父子层级提示。

时间条与文本区可分离：

- 窄屏只显示名称和条形。
- 宽屏同时显示摘要。

### 3.7 详情检查器

Tab：

- `概览`：来源、状态、类型、时间、时长、模型、工具、token、摘要。
- `预览`：输入、输出、错误预览。
- `原始内容`：格式化 JSON，可复制、折叠。

顶部操作：

- 定位到父调用。
- 定位到同轮次下一条。
- 复制调用摘要。

## 4. 视觉系统

### 4.1 颜色

浅色主题：

- 页面底色：`#f6f6f3`
- 主面板：`#fdfdfb`
- 文本：`#171716`
- 次文本：`#666660`
- 边框：`#deded8`
- 交互强调：`#2563eb`
- 成功：`#16803c`
- 警告：`#b56a00`
- 错误：`#c53b3b`

深色主题：

- 页面底色：`#151513`
- 主面板：`#1c1c1a`
- 文本：`#f1f1eb`
- 次文本：`#aaa9a1`
- 边框：`#34342f`
- 交互强调：`#6f9cff`
- 语义色保持可区分并满足对比度。

约束：

- 蓝色只用于交互和选中。
- 绿色、黄色、红色只用于状态。
- 不使用紫色渐变、彩色光晕或装饰性 blob。

### 4.2 排版

- 正文和标题：IBM Plex Sans。
- 时间、ID、数值、原始 JSON：IBM Plex Mono。
- 页面标题 20px。
- 区块标题 14px。
- 正文 13px。
- 列表摘要 12px。
- 数字使用等宽字形，便于比较。

### 4.3 形状

- 圆角统一为 6px。
- 按钮和输入使用 6px。
- 标签可使用 4px。
- 不使用大面积圆角卡片。

### 4.4 边框与阴影

- 主要使用 1px 边框和背景层级分隔区域。
- 只在浮层、抽屉和对话框使用阴影。
- 阴影带背景色倾向，不使用纯黑大阴影。

## 5. 数据视觉编码

| 维度 | 编码 |
|---|---|
| 开始时间 | 条形水平起点 |
| 持续时长 | 条形宽度 |
| 类型 | 图标与泳道位置 |
| 状态 | 条形边框、图标和状态文本 |
| 父子关系 | 左侧缩进、连接线、详情跳转 |
| 选中 | 2px 强调边框和行背景高亮 |
| 搜索命中 | 文本高亮 |
| 错误 | 红色状态符号和错误摘要 |

不只用颜色表达状态。失败调用必须同时有图标或文本。

## 6. 核心交互

### 6.1 选择调用

- 点击行或条形，更新选中。
- 选中后详情检查器加载对应调用。
- 总览轨道和瀑布列表同步高亮。
- URL 更新 `call` 参数。

### 6.2 时间缩放

- 使用工具栏缩放按钮或拖动时间轴端点。
- 总览轨道显示当前可见窗口。
- 缩放不改变滚动位置时，保持选中调用可见。
- 双击空白区域恢复全量时间域。

### 6.3 按轮次定位

- 视图切换为轮次时按轮次分组。
- 点击轮次标题滚动到该组。
- 筛选轮次后 KPI 显示当前筛选范围。

### 6.4 搜索

- 输入后 200ms 防抖更新。
- 命中项显示高亮。
- `下一步` 和 `上一步` 跳转命中。
- 无命中时显示清除搜索操作。

### 6.5 导入

步骤：

1. 选择文件或粘贴 JSON。
2. 展示检测到的 adapter 和置信度。
3. 无法识别时显示字段映射。
4. 展示调用数、轮次、错误和脱敏提示。
5. 用户确认后保存并打开。

### 6.6 键盘

| 快捷键 | 行为 |
|---|---|
| `J` / `ArrowDown` | 下一个调用 |
| `K` / `ArrowUp` | 上一个调用 |
| `Enter` | 聚焦详情或展开 |
| `Esc` | 关闭抽屉或清除浮层 |
| `/` 或 `Ctrl+K` | 聚焦搜索 |
| `R` | 切换轮次视图 |
| `+` / `-` | 时间轴缩放 |

快捷键按钮必须提供 tooltip。

## 7. 状态设计

### 7.1 加载状态

- 使用与工作台结构一致的骨架。
- 左栏列表、KPI、时间轴和详情分别占位。
- 不使用居中旋转 spinner 作为主加载体验。

### 7.2 空状态

- 首次打开：提供“加载示例”和“导入 JSON”。
- 搜索无结果：显示关键词、清除筛选和返回全部。
- 会话无调用：提示数据格式问题，并提供原始 JSON 查看。

### 7.3 错误状态

- 导入错误：在对应步骤内显示。
- 持久化失败：顶部非阻断警告，说明当前为内存模式。
- 单条调用时间错误：该行显示不可定位占位，不影响其他行。

### 7.4 进行中

- 会话状态为 running 时，顶部显示当前状态。
- 缺失 endedAt 的最后调用可显示为进行中。
- 首版不做实时流式更新，只展示导入快照。

## 8. 可访问性

- 所有交互元素可键盘访问。
- 行选择使用可聚焦元素并暴露 `aria-selected`。
- 时间轴提供文本摘要。
- 状态不只依赖颜色。
- 对比度达到 WCAG AA。
- 支持 `prefers-reduced-motion`。
- 图表区域提供“表格视图”作为等价信息入口。
- 抽屉和对话框管理焦点。

## 9. 动效

只使用以下动效：

- 行 hover 背景变化 120ms。
- 选中态 120ms。
- 抽屉滑入 180ms。
- 详情 Tab 切换 120ms。
- 缩放结束后的视图平滑过渡。

不使用循环脉冲、漂浮粒子、滚动视差或大面积入场动画。

## 10. 参考图对齐点

- 保留左侧会话导航。
- 保留顶部时间、轮次、调用切换。
- 保留中央时间轨道和调用列表。
- 保留右侧概览、预览、原始内容详情结构。
- 增加明确 KPI 带，确保评审核验总时长和轮次。
- 增加搜索、筛选、父子关系和错误状态，提升通用性。
- 不复制参考图的品牌元素和具体布局比例。
