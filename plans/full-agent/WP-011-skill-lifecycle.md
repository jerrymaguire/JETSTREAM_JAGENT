# WP-011 Skill 生命周期

## 1. 目标

把 Skill 从静态说明文件升级为可验证、可版本化、可回归的复用能力。

## 2. 范围

- 包含：版本、owner、content hash、实际生效版本、显式加载验证、自动选择验证、反例、缺输入、脚本治理和变更回归。
- 不包含：Subagent 绑定和跨 Agent 共享。

## 3. 关键规则

- Skill 保存稳定方法，不固化当前项目规则。
- 显式加载是否成功以实际模型请求为准。
- 自动选择使用干净会话验证。
- Skill 脚本必须经过 Tool Governance 和 Sandbox。
- 运行记录保存实际生效版本。

## 4. 验收

- [ ] Skill 页面显示版本、owner 和来源。
- [ ] 可执行显式加载测试。
- [ ] 可执行自动选择正例和反例。
- [ ] 缺输入时保留 unknown。
- [ ] 脚本失败不被写成通过。
- [ ] Skill 修改后可比较新旧版本。

## 5. 负责角色

- 后端开发
- 前端开发
- 测试
- 架构师
