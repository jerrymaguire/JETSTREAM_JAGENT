# WP-001 基础工程与运行骨架

## 1. 目标

建立同时包含 Vue、FastAPI、SQLite 和 Pi Sidecar 的可运行工程骨架。

## 2. 范围

- 包含：目录结构、依赖、配置、迁移、健康检查、开发启动脚本。
- 不包含：真实模型调用、业务页面和工具实现。

## 3. 关键规则

- FastAPI 默认只监听 `127.0.0.1`。
- 用户数据写入独立 `data/`，不进入 Git。
- Pi 版本固定。
- 前后端和 Sidecar 都可独立测试。

## 4. 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 服务健康 |
| GET | `/internal/health` | Sidecar 管理状态 |

## 5. 验收

- [ ] `pnpm` 前端可构建。
- [ ] `uvicorn` 可启动。
- [ ] Node Agent Host 可构建。
- [ ] SQLite 迁移可执行。
- [ ] 目录和日志策略符合设计。

## 6. 负责角色

- 架构师
- 后端开发
- 前端开发
- 运维
