# WP-007 Trace 与作业轨迹图

## 1. 目标

把实时 Pi 事件转换为作业要求的结构化轨迹，并提供总览、瀑布和详情。

## 2. 范围

- 包含：事件持久化、Span 构建、KPI、时间轴、筛选、详情和导入。
- 不包含：分布式链路追踪后端。

## 3. 关键规则

- 总运行时长来自最早开始和最晚结束事件。
- 每次调用必须有开始时间、持续时长和摘要。
- LLM、Tool、Approval、Compaction 使用不同类别。
- 事件先持久化再广播。

## 4. 验收

- [ ] 可看到总时长和轮次。
- [ ] 可看到每次调用开始时间和持续时长。
- [ ] 可看到内容摘要。
- [ ] 父子关系正确。
- [ ] 实时和历史轨迹一致。

## 5. 负责角色

- 前端开发
- 后端开发
- 测试
