# WP-006 Skill、Context 与 Memory

## 1. 目标

实现 Pi 标准 Skill 加载、上下文分层和长期记忆。

## 2. 范围

- 包含：Skill 扫描、信任、启用、显式调用、Context 规则、OKF 记忆。
- 不包含：向量数据库和跨用户共享。

## 3. 关键规则

- Skill 完整正文按需加载。
- 未信任项目 Skill 不加载。
- Context 优先级固定。
- 记忆写入保留来源。
- 记忆不是系统安全指令。

## 4. 验收

- [ ] Skill 可被发现和展示。
- [ ] 项目信任阻断生效。
- [ ] 模型可按需读取 SKILL.md。
- [ ] 记忆摘要进入上下文。
- [ ] 记忆可搜索、读取、写入和删除。

## 5. 负责角色

- 后端开发
- 前端开发
- 架构师
