# WP-005 工具、沙箱与审批

## 1. 目标

实现可被模型调用、可校验、可审批、可取消和可审计的工具运行时。

## 2. 范围

- 包含：Tool Registry、文件工具、搜索、patch、命令、Git、Sandbox、审批、审计。
- 不包含：浏览器自动化和第三方 MCP。

## 3. 关键规则

- 未知工具拒绝。
- 参数不合法拒绝。
- plan 模式禁止写操作。
- 高风险调用等待审批。
- 命令环境移除密钥。
- 参数变化导致审批失效。

## 4. 验收

- [ ] 可选工具清单正确。
- [ ] 路径穿越被阻止。
- [ ] 写文件需要批准。
- [ ] 命令超时可终止。
- [ ] Trace 有工具输入、输出和耗时。

## 5. 负责角色

- 后端开发
- 前端开发
- 测试
- 架构师
