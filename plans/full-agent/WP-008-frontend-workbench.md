# WP-008 前端 Agent 工作台

## 1. 目标

实现对话、轨迹、审批、Provider、Skill、Memory 和设置界面。

## 2. 范围

- 包含：三栏布局、流式聊天、Trace 视图、设置页、审批弹窗、主题。
- 不包含：营销首页和移动端专用 App。

## 3. 关键规则

- 首屏直接进入工作台。
- 不使用卡片套卡片。
- 状态不只依赖颜色。
- 文本和条形在桌面和移动端不重叠。
- API Key 保存后只显示掩码。

## 4. 验收

- [ ] 桌面三栏布局可用。
- [ ] 对话可流式显示。
- [ ] 轨迹可筛选和选中。
- [ ] 审批弹窗完整。
- [ ] Provider 设置可完成首次配置。
- [ ] 手机宽度可完成基本对话。

## 5. 负责角色

- 前端开发
- 测试
- 架构师
