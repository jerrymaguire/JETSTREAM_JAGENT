## 4. 通用 Agent 要求

“通用”不等于第一版内置所有 Agent 格式，而是具备稳定的扩展边界：

1. 所有输入先归一化为 `TraceSession v1` 模型。
2. adapter 负责识别输入格式和转换字段，不直接操作 UI。
3. 未识别格式可通过字段映射配置完成导入。
4. 新 adapter 不修改轨迹图、指标计算和详情面板。
5. 原始数据与归一化数据分离，便于追踪转换错误。
6. 首批支持：
   - `agent-show/v1` 标准 JSON。
   - 用户粘贴 JSON 后进入字段映射。
   - 预留 OpenTelemetry GenAI 语义约定 adapter。

## 5. 非功能需求

| 编号 | 指标 | 目标 |
|---|---|---|
| N-01 | 首屏可用 | 本地构建后 2.5 秒内出现工作台 |
| N-02 | 示例数据规模 | 支持至少 500 次调用、10 个轮次 |
| N-03 | 上限设计 | 5,000 次调用仍可滚动、筛选和定位 |
| N-04 | 交互响应 | 选择、筛选、缩放反馈在 100 毫秒内开始 |
| N-05 | 隐私 | 数据只在本机读取和存储，不上传、不埋点 |
| N-06 | 安全 | 示例和截图不包含 API Key、Token、Cookie、私有路径 |
| N-07 | 兼容性 | 最新版 Chrome、Edge、Firefox、Safari |
| N-08 | 可维护性 | 数据模型、adapter、指标和 UI 解耦 |

## 6. 约束

- 不依赖后端即可运行。
- 不把业务代码直接放在 AgentShow 根目录。
- 实现阶段代码放入 `deliverables/frontend/`。
- 输入文档目录只读。
- 凭据不得进入代码、示例数据、截图或日志。

## 7. 非目标

- 第一版不做多人协作和账号体系。
- 第一版不做云端数据上传。
- 第一版不直接连接各 Agent 运行时。
- 第一版不追求完整复刻 DeepSeek Harness。
- 第一版不实现自动费用结算，只展示已有 token 和成本字段。
